// CONCEPT & SYSTEMS DESIGN

Red Project: Economic Simulation Prototype

An exploration of emergent systems, resource management, and economy balancing. Conceived as a macro-management experience set in ancient Athens, this project strips away traditional narrative to focus purely on complex, interconnected mechanics. The core challenge was to design a banking legislature system where the environment reacts dynamically to the player's rules. Currently archived as a comprehensive 14-page Game Design Document (GDD) while I prioritize active development cycles. Though not in active production, it remains a foundational study in my approach to mathematical balancing and systems architecture for Unity 2D.

// AUDIOVISUAL WEB INSTRUMENT

Autonomous Ecosystem: Stick Stickly

A real-time visual instrument designed to interpret audio through autonomous biological systems. Built using native JavaScript, HTML5 Canvas, and the Web Audio API, the project simulates a human body functioning as an independent ecosystem. It features cellular flocking algorithms, nervous system steering behaviors, flow fields, and a Physarum network that react dynamically to audio frequencies and live user intervention. A technical study in computational performance, rendering optimization, and emergent behaviors.

Santiago Mateus

I am a digital entertainment engineering student and software developer based in Colombia, specializing in systems architecture, interactive media, and game development.

My work exists at the intersection of technical execution and creative design. I focus on building dynamic, system-driven experiences—ranging from emergent economic simulations (Unity/C#) and branching narrative architectures, to highly optimized, audio-reactive web ecosystems (JavaScript/Web Audio API).
